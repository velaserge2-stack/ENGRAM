Fisiología · Ciclo menstrual

El ciclo menstrual se divide en fase folicular, ovulación y fase lútea. La FSH estimula el desarrollo folicular y el pico de LH desencadena la ovulación.

FaseDíasHormona
Folicular1–13FSH, estradiol
Ovulación14LH
Lútea15–28Progesterona
Menstrual1–5Caída de P

La progesterona prepara el endometrio para la implantación; si no hay fecundación, el cuerpo lúteo involuciona.
